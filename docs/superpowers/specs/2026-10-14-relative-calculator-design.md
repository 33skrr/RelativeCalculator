# 亲戚计算器首版设计

日期：2026-10-14

## 目标和范围

手机优先、桌面可用的中文亲戚计算器。按用户提供的截图还原浅灰背景、白色圆角大按键及橙黄色强调色，取代此前的中式方向。不需要登录、后端或 AI 服务。

明确排除：祝福语、AI计算、关系功能、设置页、方言选择、账号、云同步、历史记录和文字查询。不仿制手机状态栏，不保留设置图标、锁或 HOT 标签。

## 布局

顶部保留“我是：女生 / 男生”，默认男生。中上部为弹性输入和结果区，初始为空；输入后显示“爸爸的哥哥”等关系链，计算后以大字突出答案。键盘上方显示“我称呼对方”或“对方称呼我”。

四列按键依次为：

1. 爸爸、妈妈、老公、老婆。
2. 哥哥、弟弟、姐姐、妹妹。
3. 儿子、女儿、切换（横跨两格）。
4. 回退、重置、＝（横跨两格）。

删除功能后的双宽按键布局为本设计提议，待用户确认。普通关系键深色文字，功能键橙黄色文字，等号橙黄色背景、白字。

手机键盘靠底、显示区弹性伸缩；短屏允许滚动，不截断按键。桌面居中显示最大宽度约 480px 的单列工具，不增加侧栏。触控高度至少 48px，保留键盘焦点、文字对比度及明确的禁用状态。

## 交互

状态包括用户性别、从“我”出发的原始关系链、称呼方向和是否已计算。

- 点击亲属键：追加关系，使用“的”连接显示，清除旧结果。按“＝”后计算，不自动展示答案。
- 点击“＝”：按当前输入、性别和方向求解。空链结果为“自己”。
- 点击“切换”：仅切换“我称呼对方 / 对方称呼我”，不反转或清空原始链；已经计算时立即重算，否则仅改变方向标签。后续亲属键仍追加到从“我”出发的原始链。
- 回退：删除最后一段并清除旧结果；空链时禁用。
- 重置：清空输入和结果，方向恢复“我称呼对方”，保留性别选择。
- 更改性别：保留输入和方向，已经计算则重算；现有链不适用时提示修改，不静默删除输入。
- 配偶键禁用状态仅与顶部用户性别选择关联（2026-10-15 更正）：选择男生时，“老公”灰色且不可点击，“老婆”可点击；选择女生时，“老婆”灰色且不可点击，“老公”可点击。更改性别后立即更新，不随关系链末端人物变化；实际关系是否可求解仍由计算引擎判断。

## 计算及边界

使用确定性规则引擎，不用 AI 猜答案。支持父母、配偶、兄弟姐妹、子女、祖孙、伯叔姑舅姨、堂表亲和常见姻亲的多级组合。年龄及家庭结构信息不足时保留合理候选，不擅自确定长幼或唯一家庭结构。

“爸爸的哥哥”正向为伯父，反向在用户为男生时为侄子、女生时为侄女。“妈妈的姐姐的女儿”无法确定年龄时保留表姐 / 表妹。无法计算时显示“暂未找到对应称呼，请检查关系”，保留原输入及回退能力。

实施阶段评估成熟亲属关系库的许可证、浏览器兼容、正反向接口和代表性案例，固定选定版本。若库不满足要求，明确实际支持范围，不能用少量硬编码宣称完整支持。

## 技术结构

React + TypeScript + Vite，纯静态前端。集中管理关系标识、文字和性别；独立计算适配层将关系链、性别、方向转换为候选结果或失败状态；独立状态逻辑处理追加、回退、重置、切换和计算。界面拆为性别选择器、显示区、方向标签和键盘，不直接依赖第三方引擎接口。样式集中定义色彩、圆角、间距及响应式规则。

本阶段不部署、不自动推送 GitHub。

## 验收

- 覆盖所有按键、男女切换、空输入、回退和重置；验证男生禁用“老公”、女生禁用“老婆”，更改性别立即更新，追加或回退关系不改变这组禁用规则。
- 验证切换方向不改关系链，反向正确使用用户性别，更改输入不保留过期答案。
- 测试常见直系、旁系、姻亲正反向，以及年龄歧义和无法求解情况。
- 在手机、窄屏、短屏及桌面检查无横向溢出、按键完整可用，截图核对结构和配色。
- 浏览器点击完整流程并检查控制台；类型检查、单元测试和生产构建通过。
